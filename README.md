# 偶棋

**设计师：和岑宁**

偶棋是一款在可选尺寸的矩形点阵上进行的双人抽象棋类游戏。红蓝双方轮流连线，通过围成封闭区域来获取分数。游戏的核心在于“偶性”约束——无论是单个交叉点还是整个封闭区域，其边界上双方线段的数量都必须满足奇偶性条件。

---

## 一、游戏组件

- **棋盘**：可选尺寸的矩形点阵，相邻点之间可以连成线段。可选的棋盘尺寸（行×列）为：  
  `11×11`、`10×11`、`10×10`、`9×10`、`9×9`、`8×9`、`8×8`、`7×8`。  
  棋盘上共有 `(行数−1)×(列数−1)` 个单位方格。
- **玩家**：红方（先手）与蓝方（后手）。
- **线段**：每次行动需在相邻两点之间画一条线段，线段的颜色与当前玩家相同（红或蓝）。

---

## 二、游戏流程

1. 游戏开始前，玩家从可选尺寸中选择一种棋盘。
2. 红方先行，之后双方轮流行动。
3. 在自己的回合，玩家必须在棋盘上选择一条尚未被占用的线段进行连接。
4. 线段必须连接两个**相邻**的点（水平或垂直，不允许斜连）。
5. 游戏持续进行，直到双方都无法走出合法棋步，游戏结束并结算最终分数。
6. 游戏过程中，玩家可以点击“悔棋”按钮撤销上一步落子（每次只能悔一步，悔棋后按钮禁用，直到下一次落子）。
7. 点击“重玩”按钮将返回棋盘尺寸选择界面。

---

## 三、详细规则

### 1. 连通性约束

除先手红方的第一步外，每次新连的线段必须与棋盘上**任意一条已有线段**共享至少一个端点。  
这一规则保证了所有已画线段在几何上是道路连通的。

### 2. 点规则（偶点条件）

如果一条线段完成后，使得某个**内部点**（非棋盘边缘或角落）的上下左右四条边全部被占用，则该点周围的四条线段中，红蓝双方的数量必须均为偶数（即红色数量为偶数，等价于蓝色数量也为偶数）。  
- 允许的组合：0红4蓝、2红2蓝、4红0蓝。
- 禁止的组合：1红3蓝、3红1蓝。

棋盘边缘和角落的点不受此限制。

### 3. 区域规则（偶边界条件）

如果一条线段完成后，形成了新的**封闭图形**，则该封闭图形的**周围线**（外边界）中，红蓝双方的数量必须均为偶数。  
- 封闭图形是指无法通过未占用边与棋盘外部连通的格子集合。
- 周围线不包含封闭图形内部的线段。
- 若周围线红蓝数量不满足偶性，则该步非法。

### 4. 计分规则

当一条线段合法地围成一个新的封闭图形后，根据该图形周围线的颜色占比计算分数：

- **全红或全蓝**：该方获得等于封闭图形**净面积**的分数。
- **一方占优（红多于蓝或蓝多于红）**：该方获得净面积一半的分数。
- **双方颜色数量相等**：双方均不得分（0分）。

分数的最小单位为 0.5 分。  
封闭图形一旦计分，其内部区域被冻结，任何玩家都不能再在冻结区域内部添加新的线段（已存在的线段保留）。

### 5. 嵌套与复连通区域

如果封闭图形内部还包含其他已经计分的封闭区域（即形成“眼”），则：

- 该图形的净面积 = 外边界内部的总方格数 − 内部所有已计分区域的净面积之和（每个格子只扣除一次）。
- 判断边界偶性与归属时，只考虑最外侧的边界，内部“眼”的边界不参与。
- 内部已计分区域仍然保持冻结状态，不影响外部区域的计分。

### 6. 无子可走的惩罚

如果一方没有任何合法棋步可走，而另一方仍能走棋，则：

- 每当另一方成功走一步，无子可走的一方扣 0.5 分。
- 如果双方都无合法棋步，游戏立即结束，不再扣分。

---

## 四、游戏结束与胜负

- 当双方都无合法棋步时，游戏结束。
- 比较红蓝双方总分，分数高者获胜；若分数相同则为平局。
- 游戏结束后，棋盘上会显示最终比分与胜负结果。

---

## 五、界面提示

- 游戏界面始终显示当前回合方与双方实时分数。
- 已计分的封闭区域会按归属着色：
  - **红色**：红方获得全分
  - **淡红**：红方获得半分
  - **淡灰**：双方均未得分
  - **淡蓝**：蓝方获得半分
  - **蓝色**：蓝方获得全分
- 每个已计分区域内会标记其分数的绝对值，位置优先选择区域的重心格。
- 当一方无子可走时，界面会短暂提示并自动切换回合；双方无子可走时提示终局。
- “悔棋”按钮在成功落子后可用，点击后回退一步并禁用；游戏结束后不可悔棋。
- “重玩”按钮随时可用，点击后返回棋盘尺寸选择界面。

## 附录：关键概念细则

### A. 封闭图形

一组互相连通的单位方格，若无法通过任何未占用的边与棋盘外部连通，则称为封闭图形。

### B. 眼

对于一个封闭图形 R，某个不属于 R 的格子 x 被称为 R 的“眼”，当且仅当：  
从 x 出发，在不穿过 R 的前提下，无法到达棋盘外部。  
“眼的判定仅依赖 R 的几何形状，与棋盘上其他线段的状态无关。”

### C. 无眼包

将封闭图形 R 与其所有“眼”合并后得到的格子集合称为 R 的“无眼包”。

### D. 外边界（周围线）

无眼包与棋盘外部（或棋盘边缘以外的虚拟外部）之间的所有已占用线段，即为该封闭图形的外边界。  
- 简单区域（无眼）的外边界就是围成它的所有线段（包括与其他区域共享的边）。
- 复连通区域的外边界不包含它与内部眼之间的边。
- 棋盘边缘的线段同样参与外边界计数。

### E. 净面积

封闭图形计分时使用的面积为其净面积：  
**净面积 = 无眼包的总方格数 − 内部所有已计分区域的净面积之和**。  
扣除时每个格子只扣一次，即使存在多层嵌套。

### F. 边界偶性判定

外边界上红蓝线段数量必须均为偶数。在方格网格上，任何封闭图形的外边界总边数恒为偶数，因此只需检查红色数量为偶数即可保证蓝色数量也为偶数。
